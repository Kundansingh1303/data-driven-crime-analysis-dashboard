# Crime Analytics & Intelligence Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze crime patterns, temporal trends, geographical hotspots, and relationships between crime categories using real-world crime data.

## Dashboard Highlights

### 1. Crime Overview
- Analyzed 34K+ crime records.
- Explored 8 districts, 46 neighborhood clusters, 9 offense types, and 3 crime methods.
- Identified crime distribution across different categories and districts.

### 2. Temporal Crime Analysis
- Analyzed monthly and hourly crime trends.
- Compared weekday and weekend crime patterns.
- Examined crime distribution across morning, evening, and night shifts.

### 3. Crime Hotspots & Relationship Analysis
- Visualized geographical crime hotspots using latitude and longitude.
- Compared crime distributions across districts and neighborhood clusters.
- Explored relationships between offense types and crime methods.

### 4. Executive Crime Report
- Highlighted key crime statistics and KPIs.
- Identified the peak crime month, top crime district, and most common offense category.
